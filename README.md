# dsh-token-usage-panel

在侧边栏加一个 **「用量统计」** 入口（位于「插件」与「自动化任务」之间）。点开后是整页的用量面板，顶部有**全局时间范围**：一排预设（全部 / 今天 / 昨天 / 前天 / 近三天 / 近一周 / 近一个月），以及**开始 / 结束日期选择器**（中文月历：周一起始的「一二三四五六日」、「‹ ›」翻月、「« »」翻年、底部「今天 / 清除」；开始日从 00:00:00 算起，结束日含 23:59:59；可只填一端，清空即不限）。切换后指标、饼图、会话 Top 5、对话记录一起变化：

- **统计指标**：总花费、总 Token（含缓存命中率）、对话数、项目数；
- **按项目统计 · 消耗占比**（左栏）：花费占比饼图，默认只显示色块；鼠标悬停某一片时它按弹性曲线放大，并在旁边显示项目名与占比（占比 >5% 的项目单独成片，≤5% 合并为「其他」，悬停「其他」可看成员）；
- **按会话统计 · 消耗 Top 5**（右栏，保持列表样式）；
- **对话记录（按轮次）**：每一次对话里**每一轮**单独一行，含该轮开始时间、所属会话、项目、模型、该轮 Token 与该轮花费；表格下方翻页，每页可选 10 / 20 / 50 / 100 轮；点标题可直接打开该会话。

## 数据从哪来（复用已有的金额插件）

本插件**不读会话日志、不含价格表**。页面只是把组合里已有的三个会话投影聚合起来：

| 投影 | 来源 | 用途 |
| --- | --- | --- |
| `tokenUsage` | `@deepseek-ai/dsh-token-meter` | 四个 token 桶（未缓存输入 / 缓存读取 / 缓存写入 / 输出） |
| `tokenCost` | `dsh-token-usage-cost`（已有的「花费金额」插件） | 按每次调用实际时刻与模型计价的 CNY 花费、峰/闲拆分、按模型明细 |
| `tokenTurns` | `dsh-token-usage-cost`（1.1.0 起） | 每轮一条：该轮四个 token 桶、该轮 CNY 花费、该轮用到的模型 |

三个值都通过会话目录（`ctx.sessions.list`）到达浏览器：活动会话来自投影推送，历史会话来自持久化的投影缓存。

**时间范围**按本地日历日切分（今天 00:00 起、昨天 00:00–今天 00:00、前天、近三天 = 今天+前两天、近一周 = 7 个日历日、近一个月 = 30 个日历日）。选「全部」时用会话级总额（即时可得）；选具体区间时改用 `tokenTurns` 的逐轮时间聚合，所以会话的金额会按落在区间内的轮次计入。

「项目」的归组规则：会话属于某个工作区时按工作区归组；没有 attach 到工作区、但 `cwd` 正好等于某个工作区目录的会话（常见于子代理会话）也归到该工作区；其余按 `cwd` 目录归组，目录名作项目名，悬停可看完整路径。所以「项目数」= 有消耗的工作区数 + 有消耗的独立目录数。

历史会话的缓存行如果早于某个投影，页面会用 `ctx.sessions.refreshProjections(id)`（Host 冷读并回写缓存，单飞、可重复调用）把缺的投影补齐，所以第一次打开会看到「正在汇总 N 个会话…」，之后就走缓存。**没装 `dsh-token-usage-cost`（或版本低于 1.1.0、没有 `tokenTurns`）时，会话级统计仍有 Token，但「对话记录」没有轮次可列，页面会给出提示。**

## 安装

```sh
# 插件页 → 插件 → 添加 → 本地目录，选择本目录
# 等价于 plugin_manager install_bundle <本目录绝对路径>
```

装好后侧边栏立即出现「用量统计」；点击即可打开面板。

## 访问范围

- **读**：会话目录（会话 id、标题、cwd、活动时间、所属工作区）与上面三个投影的数值；不读消息正文、工具输出、凭据、文件系统。
- **写**：只往页面 `<head>` 插一段本插件自己的 CSS（卸载时移除），并注册一个侧边栏行、一个主面板；不写 DOM 其它位置、不改会话。
- **不发**：没有任何网络请求。

## 已知限制

- 只有 `tokenCost` / `tokenUsage` 都拿到的会话才有会话级金额；没有 `tokenTurns` 的会话不产生轮次行，读不到的会话计入顶部提示数量。
- 子代理会话（`origin: 'subagent'`）也计入总数与轮次，并打上「子会话」标签；它们没有独立工作区时跟随父会话的 `cwd` 归组。
- 每个会话只保留最近 200 轮（`tokenTurns` 的上限），更早的轮次不出现在记录里；对话记录每页默认 20 轮，可切换为 10 / 50 / 100。
- 没有逐轮数据的会话无法判断用量发生在哪一天，因此在具体时间范围下会被排除（页面会提示数量）；「全部」范围仍按会话级总额统计。
- 区间边界取浏览器本地时区的自然日，跨时区使用时「今天」跟随本机时区。
- 手动选择只到「日」：开始日 = 00:00:00，结束日包含整天到 23:59:59（内部按次日 00:00 的开区间实现）；只填开始或只填结束都可以，两端都清空即等同「全部」。
- 日期控件是本插件自己画的月历，而不是原生 `input[type=date]`——原生控件的语言跟随应用表单 locale（这里是英文），没法用主题 token 变成中文。
- 预设会把两个日期都填上（例如「今天」= 开始今天、结束今天，「近一周」= 开始 6 天前、结束今天）。
- 选中预设后再手动改时间会进入「自定义」状态（预设胶囊不再高亮，旁边出现「自定义」标记）。
- 饼图按花费占比切分：占比 ≤5% 的项目会并入「其他」；若没有任何项目高于 5%，则保留花费最高的那个项目名称，避免出现一整块「其他」。
- 价格口径完全沿用 `dsh-token-usage-cost`：中国法定节假日按高峰计价、价格表外的模型按 `deepseek-flash` 计价。
- 单次打开最多补齐 80 个缺失投影（2 个并发，按最近活动优先），之后可点「重新汇总」再补一轮。
